# NetPilot

برنامج لإدارة شبكات هوتسبوت MikroTik: البطاقات، والبيع، ونقاط البيع، والمشتركين، والتقارير.

**[⬇️ تنزيل آخر إصدار](https://github.com/0xibrR/netpilot/releases/latest)**

1. نزّل الملف الذي ينتهي بـ `.exe` وافتحه.
2. إذا ظهر `Windows protected your PC` فاضغط `More info` ثم `Run anyway`، لأن البرنامج غير موقّع رقمياً.
3. بعد التثبيت اضغط `F1` داخل البرنامج لدليل الاستخدام.

يحتاج Windows، وراوتر MikroTik بنظام RouterOS 7.1 أو أحدث. التحديثات تصل من داخل البرنامج.
